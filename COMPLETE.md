## 🚀 To Launch (5 steps, 30 minutes)

### 1. Create Supabase Project
- Go to https://supabase.com
- Create project
- Copy URL & key to `.env.local`

### 2. Run Database Migration
- Copy `frontend/src/lib/supabase.migration.sql`
- Paste in Supabase SQL Editor
- Run query

### 3. Get API Keys
- OpenRouter: https://openrouter.ai (free)
- Add to `.env.local`

### 4. Test Locally
```bash
cd frontend
npm install
npm run dev
# Visit http://localhost:3000
```

### 5. Deploy to Vercel
- Push to GitHub
- Import on Vercel
- Set env variables
- Done!
